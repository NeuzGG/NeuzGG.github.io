NeuzStrap

The potato-friendly Roblox launcher.

A ~0.5 MB Roblox bootstrapper built around one question: how do you make Roblox playable on a weak PC? It scans your hardware, picks a profile, and only uses the FastFlags Roblox actually accepts. No fake "FPS boost" flags.

  • One-click Balanced, Potato and Ultra Potato profiles
  • Game Booster: CPU priority, free RAM, force the strong GPU
  • Server location notice, one-click rejoin, Discord Rich Presence
  • Cleaner, mods, custom cursors and a FastFlag editor

02 C# · Windows v1.1.0 0

NeuzBlox

Run every Roblox account at once.

A 252 KB multi-instance launcher. It holds the lock Roblox checks, gets a fresh launch ticket for each account, and tiles every client side by side. It never touches the Roblox process: no injection, no memory edits.

  • Unlimited accounts with sessions that refresh themselves
  • Join a place, a private server, a job ID or a friend
  • Live status per client: PID, uptime, the game it's in
  • Grid, column, row and cascade tiling, plus Rich Presence

03 TypeScript · Node.js raya.js 1.0.0 1

Raya

The Lavalink v4 client that keeps the music playing.

A fast, resilient library for Discord music bots. Players survive bot restarts, dead nodes and network blips. There's also an official Raya bot built on it that you can add to your server today.

  • Restart-proof players with v4 session resuming
  • Multi-node failover and load-aware balancing
  • Smart autoplay, filters, lyrics and SponsorBlock
  • Works with discord.js, Eris, Oceanic, or anything with send
